# Archive

Historical, not maintained. These documents describe work that is done, an
incident that is closed, or a one-off checklist for a PR that has long since
merged. They are kept for the paper trail, not as a guide for building or
operating Mission Control today — if something here contradicts
[PRINCIPLES.md](../PRINCIPLES.md), [ROADMAP.md](../ROADMAP.md) or an ADR in
[decisions/](../decisions/), those win.

Links inside archived files may point to other things that moved or no
longer exist; they are not fixed up going forward.
