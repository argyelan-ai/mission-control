# Practice repo

A small project Mission Control created for your first agent job. None of
your own code is in here, so nothing of yours can break.

- `practice/parse.py` — `parse()` turns `"name=Ada; lang=en"` into a dict. It has no test yet.
- `practice/slug.py` — `slugify()`, with a test in `tests/test_slug.py`.

Run the tests (Python 3, nothing to install):

```sh
python3 -m unittest
```

This repository lives only on your computer. It has no remote; nothing is
pushed anywhere.
